Ejercicio 1
Decir V o F a la siguiente afirmación y justificar la respuesta:

Declarar el siguiente método en la clase A:


 public class A {
     static int method() {
         synchronized (A.class) {
             // "acá va el código que corresponda, con el return correspondiente"
         }
     }
 }


es equivalente a haberlo codificado de la siguiente forma:


 public class A {
     static synchronized int method() {
         // "acá va el código que corresponda, con el return correspondiente"
     }
 }


Ejercicio 2
El siguiente código implementa un Stack. Escribir un código java que utilice este stack y
pruebe que se pueden generar inconsistencias del stack debido al mal manejo
thread-safety.


 public class Stack {
     private static final int MAX_SIZE = 10;
     private int top = 0;
     private final int[] values = new int[MAX_SIZE];

     public void push(final int n) {
         if (top == MAX_SIZE) {
             throw new IllegalStateException("stack full");
         }
         values[top++] = n;
     }

     public int pop() {
         if (top == 0) {
             throw new IllegalStateException("stack empty");
         }
         return values[--top];
     }
 }

                super();
                this.tope = tope;
